Comment vos données sont traitées dans INVOOFFICE

INVOOFFICE est conçu pour traiter vos documents de facturation localement, dans votre navigateur. Voici comment cela fonctionne et où vos données sont conservées.

Notre philosophie

Vos documents de facturation — devis, factures, avoirs, bons de livraison — contiennent des informations importantes : le nom de vos clients, vos tarifs, le détail de vos prestations. Ces informations vous appartiennent.

INVOOFFICE a été conçu pour que la génération de vos documents et le stockage de vos données de facturation s'effectuent localement sur votre appareil, sans dépendre d'un serveur distant pour ces opérations.

Comment fonctionne INVOOFFICE

Quand vous créez un document avec INVOOFFICE, voici ce qui se passe :

  1. Vous remplissez le formulaire (informations de l'entreprise, client, lignes de facturation).
  2. Quand vous cliquez sur « Générer le document PDF », l'application construit le document au format HTML.
  3. La bibliothèque html2canvas capture ce rendu et le transforme en image.
  4. La bibliothèque jsPDF convertit cette image en fichier PDF.
  5. Le PDF est téléchargé sur votre appareil.

Ce processus s'exécute entièrement dans votre navigateur. Le contenu de vos documents de facturation — client, lignes, montants — est traité localement sur votre appareil.

Où sont stockées vos données

INVOOFFICE utilise deux mécanismes de stockage intégrés à votre navigateur :

Le LocalStorage

C'est un espace de stockage simple fourni par tous les navigateurs modernes (Chrome, Firefox, Edge, Safari). Il contient :

  • Les informations de votre entreprise (nom, adresse, ICE, IF, etc.)
  • Votre liste de clients enregistrés
  • L'historique de vos documents générés (numéro, date, client, type)
  • Vos préférences (langue, thème clair ou sombre)

L'IndexedDB

Une base de données plus avancée, également intégrée au navigateur. Elle est utilisée comme miroir de sauvegarde du LocalStorage, pour plus de fiabilité.

Ces données sont conservées sur votre appareil, dans le navigateur que vous utilisez. Elles ne sont accessibles que par le site invoooffice.com, depuis ce navigateur.

Comment supprimer vos données

Vous pouvez à tout moment supprimer l'intégralité de vos données locales :

  • Ouvrez les outils de développement (touche F12).
  • Allez dans l'onglet « Application » (Chrome) ou « Stockage » (Firefox).
  • Dans « Stockage local », trouvez le domaine invoooffice.com.
  • Supprimez toutes les entrées commençant par fb_.
  • Vous pouvez également vider complètement les données de navigation de votre navigateur.

À propos du stockage local

Pour utiliser INVOOFFICE, vous devez créer un compte. Après votre inscription, vous effectuez le paiement unique de 300 DH et notre équipe active votre compte. Vous bénéficiez ensuite d'un accès à vie, sans abonnement.

La gestion de votre compte (identifiants, statut d'activation) est la partie qui nécessite un serveur. En revanche, pour la création et la gestion de vos documents, l'application privilégie un traitement local :

  • La génération des PDF s'effectue dans votre navigateur, sans envoi du contenu de vos documents vers un serveur distant.
  • Le stockage de vos données de facturation (clients, historique, informations d'entreprise) se fait localement, sur votre appareil.
  • Vous pouvez à tout moment exporter une sauvegarde de vos données pour les conserver ou les transférer.

Questions fréquentes

Mes documents sont-ils transmis à un serveur ?

La génération du PDF se fait entièrement dans votre navigateur. Le contenu de vos documents de facturation est traité localement sur votre appareil.

Puis-je supprimer toutes mes données ?

Oui, à tout moment. Vous pouvez supprimer les données depuis les outils de développement de votre navigateur (F12 > Stockage local > supprimer les entrées fb_), ou en vidant les données de navigation.

Où sont stockées mes données de facturation ?

Vos données de facturation (clients, historique, informations d'entreprise) sont conservées localement dans le stockage de votre navigateur. Vous pouvez les exporter à tout moment pour les sauvegarder ou les transférer sur un autre appareil.

Puis-je utiliser INVOOFFICE hors ligne ?

Oui. Une fois l'application chargée dans votre navigateur, vous pouvez créer et gérer vos documents même sans connexion Internet. Vos données restent accessibles sur votre appareil.

Dois-je créer un compte pour utiliser INVOOFFICE ?

Oui. Vous devez créer un compte pour accéder à INVOOFFICE. Après l'inscription, vous effectuez le paiement unique de 300 DH. Une fois votre paiement validé par notre équipe, votre compte est activé et vous bénéficiez d'un accès à vie, sans abonnement.
