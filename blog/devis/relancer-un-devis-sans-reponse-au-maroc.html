Comment relancer un devis sans réponse au Maroc ?

Un devis reste sans réponse ? Voici une méthode concrète pour relancer sans insister, avec des messages prêts à copier et une checklist avant chaque relance.

Pour relancer un devis sans réponse, attendez un délai raisonnable, puis envoyez un message court qui rappelle le projet, le montant et la prochaine étape attendue. Une bonne relance ne consiste pas à insister : elle sert surtout à vérifier que le devis a bien été reçu, à identifier un éventuel blocage et à faciliter la réponse du client.

Au Maroc, le devis doit rester cohérent avec les informations commerciales que vous avez communiquées au client. Avant de relancer, vérifiez donc le document, son montant, les coordonnées du client, les prestations proposées et les conditions que vous avez indiquées. Vous éviterez ainsi de relancer sur la base d’un document devenu obsolète.

Vérifiez le devis avant de relancer

La première relance est plus efficace lorsque vous maîtrisez exactement ce que le client a reçu. Ouvrez votre copie du devis et contrôlez les éléments qui peuvent provoquer une question ou une hésitation.

  • Identité du client : vérifiez le nom, la raison sociale si elle est utilisée et les coordonnées.
  • Prestations : assurez-vous que le détail correspond bien à ce qui a été demandé.
  • Montant : contrôlez le total et les éventuelles remises.
  • Informations de votre entreprise : vérifiez les informations présentes sur le document, notamment celles que vous utilisez habituellement pour identifier votre activité.
  • Présentation : assurez-vous que le PDF envoyé est lisible et professionnel.
  • Version : si une modification a été demandée entre-temps, ne relancez pas avec une ancienne version.

Ne transformez pas la relance en nouvelle proposition commerciale. Si le client a demandé une précision, répondez à cette question. Si le devis doit être corrigé, modifiez-le d’abord, puis envoyez la version actualisée.

Choisissez le bon message de relance

Le meilleur message dépend de la raison pour laquelle le devis est resté sans réponse. Si vous ne connaissez pas cette raison, partez du principe que le client peut simplement avoir besoin d’un rappel.

Client intéressé mais silencieuxQuestion simple sur la suite du projetFaire émerger un blocage
Modification demandéeRappel de la version actualiséeFaire valider le nouveau devis

Évitez les formulations culpabilisantes comme « je n’ai toujours pas de réponse ». Préférez une question qui permet au client de répondre facilement : « Avez-vous pu prendre connaissance du devis ? » ou « Souhaitez-vous que nous reprenions un point du devis ? ».

Relancez progressivement, sans multiplier les messages

Une relance efficace suit une logique simple : rappeler, aider, puis clôturer proprement. Vous n’avez pas besoin d’envoyer plusieurs messages rapprochés pour obtenir une décision.

  1. Retrouvez le devis exact : identifiez le client, le projet et la version envoyée.
  2. Contrôlez le contenu : vérifiez les montants, prestations et informations du document.
  3. Envoyez une première relance : restez bref et demandez simplement si le client a pu consulter le devis.
  4. Répondez aux objections : si le client demande une précision, traitez uniquement le point concerné.
  5. Actualisez le devis si nécessaire : modifiez le document plutôt que de multiplier les explications dans les messages.
  6. Faites une dernière relance : proposez au client de vous indiquer s’il souhaite poursuivre, modifier le projet ou le reporter.
  7. Conservez l’historique : gardez la trace du devis et de ses versions pour pouvoir reprendre le dossier plus tard.

Modèles de messages à copier

Le message doit être assez court pour être lu rapidement. Voici quatre modèles que vous pouvez adapter.

Relance simple

Bonjour, je reviens vers vous concernant le devis pour votre projet. Avez-vous pu en prendre connaissance ? Je reste disponible si vous souhaitez que nous reprenions un point ensemble.

Après une modification

Bonjour, je reviens vers vous concernant le devis mis à jour pour votre projet. J’ai pris en compte les éléments évoqués précédemment. Pouvez-vous me confirmer si cette nouvelle version vous convient ?

Client qui hésite

Bonjour, je voulais faire un point concernant le devis envoyé pour votre projet. Si un élément vous fait hésiter, indiquez-moi simplement lequel afin que je puisse vous répondre précisément.

Dernière relance

Bonjour, je vous adresse un dernier message concernant le devis. Si le projet est toujours prévu, je peux reprendre le dossier avec vous. S’il est reporté ou abandonné, n’hésitez pas à me le signaler également.

Exemples concrets par métier

Freelance

Exemple 1 : un freelance en création graphique envoie un devis de 4 500 DH pour une identité visuelle. Le client ne répond pas. Au lieu de renvoyer tout le devis, le freelance rappelle le projet et demande si le document a bien été reçu. Si le client répond qu’il hésite sur le nombre de supports, le freelance modifie le devis pour présenter la nouvelle proposition.

Exemple 2 : un développeur freelance prépare un devis de 8 000 DH pour la création d’un site vitrine. Le client avait demandé une précision sur une fonctionnalité. La relance doit reprendre cette question, pas simplement demander une décision. Une réponse ciblée réduit le risque que le devis reste bloqué parce qu’un seul point n’a pas été compris.

Artisan

Exemple 1 : un peintre en bâtiment envoie un devis de 12 000 DH pour la rénovation de plusieurs pièces. Le client ne répond pas. L’artisan peut rappeler le chantier concerné et demander si le devis correspond toujours au besoin. Si les travaux ont évolué, il prépare une version modifiée plutôt que de discuter d’anciens montants.

Exemple 2 : un menuisier propose un devis de 18 500 DH pour des aménagements sur mesure. Le client demande finalement une autre finition. Le menuisier actualise le devis, puis relance avec un message simple indiquant que la nouvelle version tient compte de la finition demandée.

Commerçant

Exemple 1 : un commerçant qui fournit du matériel professionnel adresse un devis de 6 800 DH à une entreprise. Sans réponse, il vérifie les références et quantités avant de relancer. Son message demande si le besoin est toujours d’actualité, plutôt que de supposer que le client refuse.

Exemple 2 : un commerçant prépare un devis de 3 200 DH pour plusieurs équipements. Le client souhaite finalement retirer une référence. Le commerçant modifie le devis, vérifie le nouveau total et réimprime le document avant de le transmettre.

TPE

Exemple 1 : une petite entreprise de services envoie un devis de 25 000 DH pour une prestation destinée à un professionnel. Plusieurs personnes peuvent participer à la décision. La relance doit donc rappeler clairement le projet et faciliter la transmission du devis à la personne qui doit le valider.

Exemple 2 : une TPE propose une prestation de 15 000 DH avec une remise prévue dans le devis. Le client demande une variante. L’entreprise modifie le document pour éviter qu’une ancienne version circule, puis réimprime la version actualisée avant de poursuivre les échanges.

Quand modifier ou réimprimer le devis

Ne modifiez pas un devis uniquement pour donner l’impression qu’il est récent. Modifiez-le lorsqu’un élément commercial doit réellement changer : prestation, quantité, remise, coordonnées ou autre information du projet.

Si aucune modification n’est nécessaire, conservez la version envoyée et utilisez-la comme référence dans votre relance. Si une modification intervient, utilisez une nouvelle version claire et évitez d’entretenir plusieurs documents concurrents dans vos échanges.

La réimpression est également utile lorsque vous devez retrouver rapidement le document exact à transmettre au client. Pour un entrepreneur qui gère plusieurs demandes en parallèle, cette organisation limite les erreurs de version et les oublis.

Erreurs fréquentes

  • Relancer sans relire le devis : vous risquez de rappeler un montant ou une prestation qui a changé.
  • Envoyer un message trop long : le client doit comprendre immédiatement pourquoi vous le contactez.
  • Mettre la pression : une relance doit faciliter la décision, pas créer un conflit.
  • Multiplier les anciennes versions : cela augmente le risque que le client valide un document différent de celui que vous avez en tête.
  • Modifier le prix sans explication : si le devis change, indiquez clairement que la nouvelle version tient compte d’une demande précise.
  • Oublier les coordonnées du client : lorsque le devis doit être actualisé, reprenez les informations du dossier avant de le rééditer.
  • Ne pas conserver l’historique : sans trace du devis envoyé, il devient plus difficile de savoir ce qui a été proposé.
  • Relancer sans donner de porte de sortie : permettez au client de répondre simplement qu’il souhaite reporter ou abandonner le projet.

La checklist avant d’envoyer votre relance

  1. J’ai retrouvé le bon client.
  2. J’ai retrouvé le bon devis.
  3. Le montant correspond à la proposition envoyée.
  4. Les prestations et quantités sont correctes.
  5. Les coordonnées du client sont à jour.
  6. Je sais si une modification est nécessaire.
  7. Mon message tient en quelques phrases.
  8. Je pose une question à laquelle le client peut répondre facilement.
  9. Je sais quelle version du devis sera utilisée si le client demande une correction.

Relancer un devis sans réponse devient donc une opération simple : retrouver le bon document, vérifier son contenu, envoyer un message court et modifier le devis uniquement lorsqu’un changement réel est nécessaire. Vous gardez ainsi une démarche professionnelle tout en laissant au client un espace pour décider.

À retenir

Une relance réussie ne cherche pas à forcer une vente. Elle remet le devis au bon endroit dans la discussion, répond aux éventuelles questions et vous permet de repartir d’un document fiable. Pour les règles fiscales ou administratives qui dépassent le contenu du devis, confirmez votre cas précis auprès de la DGI, de la CNSS, de l’ANAE ou d’un comptable.
